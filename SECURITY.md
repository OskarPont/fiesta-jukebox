# Seguridad

Si encuentras un fallo de seguridad, **no abras un issue público**. Avísame en privado desde la pestaña
**Security → Report a vulnerability** de este repositorio (GitHub Private Vulnerability Reporting).

Incluye, si puedes, cómo reproducirlo y qué impacto tiene. Intentaré responder en una semana.

Solo se da soporte a la última versión de la rama `main`.
